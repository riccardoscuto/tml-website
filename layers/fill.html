Layer Type · Fill

The Fill Layer

Parametric solid values — colour, roughness, metallic — that you can change anytime. The primer almost every material starts from.

A Fill layer — roughness swept live from glossy to matte.

What it does

A fill layer is a flat, editable set of values: a base colour, a roughness, a metallic amount. No painting, no texture — just sliders you can revisit whenever.

Thanks to cumulative routing, a single fill can drive several channels at once: set the colour, the metallic and the roughness of your base in one layer.

The Parametric Base

Set It, Change It Anytime.

Base Color

A solid diffuse colour for the whole layer.

Metallic

Dielectric to metal in one 0–1 slider.

Roughness

Mirror-sharp to fully matte.

Cumulative routing

One fill feeds Base Color, Metallic & Roughness together.
