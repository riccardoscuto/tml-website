What it is

A layer stack that compiles to a real Blender shader.

If you texture in Blender, you usually choose between hand-wiring a node graph or round-tripping to Substance. TLM is a third option: author the material as a stack of layers inside Blender, route each layer to the PBR channels it should drive, and let the addon build the underlying node tree for you. It’s aimed at people who already know Blender and want to move faster — not a closed “easy mode”.

1

Stack layers

Add paint, fill, procedural, adjustment, reference or group layers. Reorder them, set opacity, pick a blend mode — the same mental model as Photoshop or Krita. Nothing is destructive; every layer stays editable.

→
2

Route to PBR channels

Send a layer to Base Color, Roughness, Metallic, Normal, Bump, Emission, Transmission or Alpha — one layer can feed several at once. That routing is what turns a stack of layers into a complete PBR material.

→
3

Mask & finish

Gate each layer with a painted or procedural mask, then either keep iterating in the stack or convert the whole thing to standard Blender nodes and bake it for your engine.

Everything below is just more detail on these three steps.

No lock-in

The stack converts to standard Blender nodes.

TLM is a faster way to author a material, not a container that traps it. The layers are compiled into an ordinary Principled BSDF node graph, and one button converts that graph into fully editable nodes you can hand-tune, extend, or ship without the addon installed.

Layer types

Six layer types, each with a clear job.

A material is built from these six. Click a tab to see what each one does and when you’d reach for it.

Paint Layer

Brush directly onto the model

A paintable layer backed by its own image texture at the resolution you choose (512–4096), with full alpha and per-layer blend modes. Because it’s an image, it follows the model’s UVs.

Reach for it when: you need something in a specific place — a logo, a decal, hand-painted dirt or wear that has to sit exactly where you put it.

Fill Layer

A flat, parametric value

A solid colour plus roughness and metallic values, all editable at any time — no painting, no image. One fill can drive several channels at once (e.g. base colour + roughness + metallic together).

Reach for it when: you need the base “primer” layer almost every material starts from, or a clean tint to grade everything above.

Procedural Layer

A generated pattern, no unwrap needed

24 patterns — Noise, Voronoi, Wave, Marble, Musgrave, Gradient, Brick, Hex, Wood, Tiles, Weave, Cracks, Caustics and more — each parametric (scale, detail, distortion, colour ramp, coordinate transforms). They generate in 3D space, so they wrap a model with no UV unwrap required. UV is available as an optional coordinate mode when you want the pattern to follow existing UVs.

Reach for it when: you want resolution-independent surfaces — stone, fabric, panels, organic noise — without spending texture memory or unwrapping.

Adjustment Layer

Re-grade what’s below it

Five non-destructive operations — Hue/Saturation, Brightness/Contrast, Levels, Color Balance and Gradient Map — applied to everything beneath, like a Photoshop adjustment layer. It can target any PBR channel, not just colour.

Reach for it when: you want to warm a whole stack, knock back an over-bright preset, or grade only the roughness without repainting anything.

Reference Layer

Reuse one pattern across channels

A reference layer borrows another layer’s pattern as its source, then applies its own blend mode, opacity, mask and channel routing. Build a wear mask once and drive base colour, metallic, roughness and bump from it independently — the Substance “smart material” idea, without baking.

Reach for it when: one chip mask should simultaneously expose bare metal, raise roughness and add relief. Edit the source once; everything that references it follows.

Group Layer

Fold related layers into one

Collapse a set of layers into a folder, reorder it, and control the whole group’s opacity at once. Groups can nest for larger material stacks.

Reach for it when: you’ve built a “rust kit” (colour + roughness + bump) and want to fade it all in or out with a single slider.

PBR routing

Every layer can drive eight PBR channels.

Routing is the core idea: a layer isn’t just “colour”. Point the same pattern at Roughness for smudges, at Bump for relief, at Emission for glow. One layer can feed several channels at once — a single Fill can set base colour, metallic and roughness in one move.

Base Color

The diffuse colour, set per layer by paint, fill, image or procedural.

Roughness

Per-layer roughness from a slider, an image, or a procedural value.

Metallic

Per-layer metallic, smooth 0–1, for bare-metal reveals and trim.

Normal

Per-layer normal maps with strength, scale and rotation — blended as true vectors across layers, not a naive RGB mix.

Bump

Relief generated from any layer’s texture or procedural, with adjustable strength and distance.

Emission

Glow colour and strength, with selective emission to gate the glow to a noise, cell or image sub-region.

Transmission

Per-layer glass / refraction weight for crystals, frosted glass and translucent inserts.

Alpha

Cutout transparency, Cycles-correct, with hashed alpha auto-enabled in EEVEE where needed.

Compositing

19 blend modes — and a different one per channel.

Each layer has opacity and a blend mode, the same way Photoshop composites pixels: Multiply grime into crevices, Screen a glow, Overlay detail without washing out what’s beneath. The difference here is that a layer can use a different blend mode on each PBR channel.

Per-channel example — rust bleed

One rust layer, four channels, four different blends — the way a real material behaves:

  • Base Color Multiply — rust stains the paint below.
  • Metallic Mix — rust is dielectric, drops to 0.
  • Roughness Mix — rust is rough, raises toward 0.9.
  • Bump Mix — rust is raised, adds relief.

Masking

Eleven mask sources — from geometry, light or a pattern.

A mask is a 0–1 factor that decides where a layer shows. In TLM every layer can carry one, built from a short pipeline you control: pick a source, optionally combine a second, refine the falloff, and it gates the layer. Most sources read the mesh or the view live — no baking.

1

Pick a source

What the mask reads from — a painted image, the mesh geometry, the view/light angle, or a procedural pattern.

→
2

Combine a second

Optional slot B blended with A — Multiply, Min, Max, Add, Subtract, Screen or Difference — each slot independently invertible.

→
3

Refine the falloff

Contrast, Levels (in / gamma / out), Softness and Blur — shape the mask edge without leaving the panel.

→
4

Gate the layer

The final factor × the layer’s opacity decides exactly where the layer contributes.

FAQ

Questions, answered.

Do my materials still work without the addon?

Yes. A TLM stack can be converted into standard Blender nodes, so the final shader isn’t trapped in a proprietary container — the .blend keeps rendering normally even if the addon isn’t installed.

Do I have to UV unwrap?

Not for procedural or smart-mask layers — they work in 3D space with no unwrap. Paint and image layers use the model’s existing UVs, and procedurals offer UV as an optional coordinate mode.

Which Blender versions are supported?

Built for Blender 5.x and tested down to 4.2 LTS. Renders in both Cycles and EEVEE Next.

Will it slow down my viewport?

Editing a value updates the existing nodes in place instead of rebuilding the whole tree, so dragging sliders stays responsive.

Does it export to game engines?

A one-click bake flattens the stack to a PBR set for Unreal, Unity or glTF, with channel packing for ORM-style maps.

Is it a subscription?

No — one-time purchase with free updates. No account, no login, no recurring fee, and it’s fine for commercial work.
