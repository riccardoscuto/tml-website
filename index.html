How It Works

Three Ideas. That's the Whole Workflow.

If you've used Photoshop layers, you already know TLM. Everything else on this page is just more depth on these three steps.

1

Stack layers

Paint, fill or procedural layers, stacked like Photoshop — reorder, set opacity, pick a blend mode. Nothing is baked in; change any layer anytime.

→
2

Send each layer to a channel

Point a layer at Base Color, Roughness, Metallic, Normal, Bump, Emission, Transmission or Alpha — one layer can feed several at once. That's your PBR material, built layer by layer.

→
3

Mask where it shows

Paint a mask, or let a smart mask read the geometry — so a layer lands only on edges, in cracks, or wherever you want. Tweak the mask once, the whole look updates live.

Layer System

Six Layer Types. Infinite Possibilities.

Adjustment Layer

Non-destructive color grading

Hue/Saturation, Brightness/Contrast, Levels and Color Balance. Adjust everything below without touching a single pixel — and route the adjustment to any PBR channel (Roughness, Metallic, Emission…), not just Base Color. Use it for: warming a whole stack, knocking back an over-bright preset, or grading only the roughness.

Adjustment layer controls
Fill Layer

Parametric solid color fills

Set a base color, roughness, metallic value — change them anytime. No painting required, fully parametric. Perfect for base materials and color foundations. Use it for: the bottom “primer” layer almost every material starts from.

Fill layer properties
Group Layer

Organize into folders

Group related layers together. Collapse, reorder, and control group opacity — just like Photoshop. Nest groups inside groups for complex material stacks. Use it for: bundling a “rust kit” (color + roughness + bump) and fading it all in with one opacity slider.

Group with nested layers
Paint Layer

Brush directly onto your model

The familiar paintable layer. Each layer gets its own image texture at your chosen resolution (512 to 4096). Full alpha support, per-layer blend modes, and live viewport preview. Use it for: logos, decals, hand-painted dirt — anything that has to sit in a specific UV spot.

Output Routing

Route Any Layer to Any Channel.

Every layer carries an Output Channel setting that decides where it ends up — paint a noise straight into Roughness, or fill a cutout straight into Alpha. No node tree to wire.

Base Color

Default. The layer drives the diffuse color of the material.

Roughness

The layer's value becomes a roughness map — paint dirt, fingerprints or scratches as smooth/rough shifts.

Metallic

The layer's value becomes a metallic mask — expose bare metal exactly where you paint.

Alpha

The layer becomes a cutout / transparency mask — with a special twist below.

Alpha Math

Send a layer to Alpha and blend modes turn into mask math.

When a layer outputs to Alpha, the blend dropdown swaps to 41 math operations — so you can combine cutout masks the way Substance Designer does: multiply two masks to intersect them, take the smooth minimum for a soft union, or threshold with greater-than. Complex cutouts, no node tree. The ones you'll actually reach for:

Multiply Add Subtract Minimum Maximum Smooth Min Power Greater Than + 33 more (rounding, trig, modulo…)

Per-Channel Branching

One Layer. Different Blend Per Channel.

Per-channel blend overrides let a single layer Multiply the base color while staying Mix on roughness — the way Substance Designer branches mask channels, native in Blender.

Rust Bleed
  • Base Color Multiply — rust stains paint & primer below.
  • Metallic Mix — rust is dielectric, drops to 0.
  • Roughness Mix — rust is rough, raises to 0.9.
  • Bump Mix — rust is raised, +0.025 distance.
Edge Wear
  • Base Color Mix — cool steel grey on chip edges.
  • Metallic Mix — raises to 1 (bare metal).
  • Roughness Subtract — fresh metal smoother than weathered paint.

+ Cumulative routing — a single Fill layer drives Base Color, Metallic and Roughness at the same time. One decision, three channels.

PBR Output

8 PBR Channels Per Layer

Every layer can independently drive Base Color, Roughness, Metallic, Normal, Bump, Emission, Transmission and Alpha — with cumulative routing: one Fill can paint base color, metallic and roughness at the same time.

Base Color

Paint or fill the diffuse color for each layer independently.

Roughness

Per-layer roughness with slider, image, or procedural fac.

Metallic

Toggle metallic per layer, smooth 0-to-1 control.

Normal

Per-layer normal maps with strength, tile scale and rotation. True vector blending across multiple layers — not naive RGB mix.

Bump

Generate displacement from any layer's texture or procedural with adjustable strength and distance.

Emission

Glow color and strength — with selective emission (gate the glow to a noise / cell / image sub-region).

Transmission

Per-layer glass / refraction weight for crystals, frosted glass and translucent inserts.

Alpha

Surface cutout with Cycles-correct transparency. Auto-detects when to enable Hashed alpha in Eevee.

Smart Masking

Masks That Think For You

A mask is a 0–1 factor that decides where a layer shows. In TLM every layer — and every PBR channel — can carry one, built from a pipeline you control end to end. Pick a source, optionally combine a second, refine the falloff, and it gates the layer. No nodes.

1

Pick a source

What the mask reads from — a painted image, the mesh geometry, the view / light angle, or a procedural pattern.

→
2

Combine a second

Optional slot B, blended with A: Multiply, Min, Max, Add, Subtract, Screen or Difference — each slot independently invertible.

→
3

Refine the falloff

Contrast, Levels (in / gamma / out), Softness and Blur — shape the edge exactly like Photoshop curves.

→
4

Gate the layer

The final factor × the layer's opacity decides precisely where the layer contributes.

11 Mask Sources — what each one reads

Image

A painted or baked black/white texture. The classic hand-authored mask — paint exactly where the layer lives.

Ambient Occlusion

Cavity mask straight from the geometry: dark in recesses, bright on exposed faces. Pools dirt & grime where it belongs.

Pointiness

Surface curvature: bright on convex edges, dark in concavities. The raw signal behind edge highlights and wear.

Edge Wear live

Convex edges + noise breakup + a sharpness control. Paint chips and scuffs that ride the model's edges — real-time, no bake.

Dirt live

Inverted AO × noise grunge. Accumulates organically in cavities — soot, dust, oxidation in the cracks.

Curvature live

Bipolar pointiness: catches both convex and concave edges with a threshold — highlight every panel seam at once.

Wireframe

A true mesh-edge mask from Blender's Wireframe node — follows the actual topology, not a faked grid.

Fresnel

Viewing-angle gradient: 0 facing the camera, 1 at the grazing silhouette. Drives iridescence, oil-slick, bubble & rim effects.

Light Angle NdotL

Normal · Sun direction, remapped 0–1: lit vs. in-shadow. With a hard ramp it’s instant binary cel-shading.

Half-Vector NdotH

Peaks at the Phong specular spot between sun and camera — shaped toon highlights and anime sparkle.

Voronoi / Pattern

Use a Voronoi (cell distance or distance-to-edge) as the mask — align its scale with a layer to drop grime exactly between stones, tiles or panels.

Two-slot compositing
  • Multiply A×B — intersect: only where both agree (edges and facing up).
  • Maximum max — union: either mask reveals.
  • Subtract A−B — carve B out of A (mask out a painted zone).
  • Min / Add / Screen / Diff — the rest of the set. Each slot has its own Invert.
Refinement chain
  • Contrast — harden a soft gradient into a crisp cutoff, or vice-versa.
  • Levels — input black/white + gamma + output range, Photoshop-style.
  • Softness — smoothstep the threshold for a feathered edge.
  • Blur — feather an image mask without re-painting it.

Two ways to apply a mask, on top of the sources above: Layer Masks gate a single layer (white reveals, black conceals); Clipping Masks clip a layer to the one below. Plus image projection — Flat, Box (triplanar), Sphere & Tube.
